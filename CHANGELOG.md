# Changelog

All notable changes are listed here. Versions follow [semantic versioning](https://semver.org/).

## 1.0.0

First stable release.

- Night-sky background for the desktop app: twinkling stars, a crescent moon, planes, rockets from both sides and shooting stars. Dark only, and still when reduced motion is on.
- Moon-phase meter band above the prompt for context and rate limits, with bars that shift from blue to amber to red and a reset time for each limit.
- Terminal version of the band as one line of text with moon emoji, colored bars and context token counts.
- Reads usage numbers only, with no network requests.
